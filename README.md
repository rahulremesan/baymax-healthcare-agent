# Baymax Healthcare Agent

Baymax is a self-hosted AI-powered personal healthcare and accountability agent designed to improve discipline, fitness, sleep, hydration, productivity, and overall well-being.

Inspired by Baymax from Big Hero 6, this project acts as a personal health companion that continuously monitors daily habits, tracks health goals, provides reminders, generates health reports, and uses AI coaching to keep users accountable.

---

## Features

### Habit Tracking

Track:

- Water Intake
- Exercise
- Walking Steps
- Sleep Time
- Wake-up Time
- Breakfast
- Learning Activities
- Alcohol Consumption
- Weight Progress

### AI Accountability Coach

Baymax analyzes daily performance and generates:

- Motivation
- Corrective Actions
- Health Insights
- Goal Reminders

### Reminder Engine

Automated reminders for:

- Wake Up
- Water Intake
- Exercise
- Meals
- Sleep

### Daily Health Score

Baymax calculates a daily score based on habit completion.

### Weekly Health Reports

Provides trend analysis and progress reports.
